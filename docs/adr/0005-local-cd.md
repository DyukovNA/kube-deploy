# ADR 0005: локальный CD на одном Mac

Статус: принято, 2026-10-04. Заменяет исходную идею обязательного Linux self-hosted runner.

GitHub Actions запускает тесты, проверку политик, сборку, Trivy и публикацию immutable SHA images в GHCR. После успешного release разработчик на Mac с k3d запускает `make deploy IMAGE_TAG=sha-<full commit sha>`. Команда проверяет, что SHA принадлежит `origin/main`, разрешает GHCR tag в digest, проверяет GitHub attestation и применяет только digest refs.

Kubeconfig и доступ к Docker/k3d остаются локальными. Отдельная VM или второй ПК не нужны; дополнительная настройка сети не нужна. Следствие: применение в локальный кластер запускается человеком, а не автоматически событием GitHub. Если автоматический CD станет обязательным, runner может вызывать тот же deploy-скрипт как отдельное расширение после оценки доступа и ресурсов.
