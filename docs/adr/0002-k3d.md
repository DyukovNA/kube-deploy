# ADR 0002: локальный кластер k3d

Статус: принято, 2026-10-04.

Для проекта используется один кластер k3d на Mac. Он создаётся и удаляется явными командами, имеет имя `kube-deploy` и context `k3d-kube-deploy`. Скрипты проверяют context перед изменением ресурсов. K3s запускается с шифрованием Secrets в datastore; встроенный Traefik отключён, чтобы входящим трафиком управлял Envoy Gateway.

Достаточность памяти Docker проверяется при clean-cluster e2e. Если 8,3 ГБ окажется мало, сначала уменьшаются requests и количество реплик учебных компонентов в пределах безопасного MVP; второй компьютер не является предпосылкой начала разработки.
