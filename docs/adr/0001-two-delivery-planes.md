# ADR 0001: два контура доставки

Статус: принято, 2026-10-04.

Системные компоненты меняются через Git и Argo CD. Пользовательские frontend и backend описываются Score; CI проверяет исходники и конфигурацию, GitHub Actions публикует образы, а локальный `make deploy` генерирует и применяет ресурсы в k3d. PostgreSQL устанавливается локальным Helm-чартом.

Это сохраняет Git как источник конфигурации системного слоя и не заставляет Argo CD управлять пользовательскими workloads. При демонстрации отдельно проверяются системный self-heal и обновление приложения.
